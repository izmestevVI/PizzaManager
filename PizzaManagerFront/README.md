🎨 Pizza Manager Frontend

Клиентская часть приложения, построенная на передовом стеке Angular 21. Проект демонстрирует современный подход к созданию SPA с акцентом на переиспользуемость компонентов и четкое разделение ответственности.

🛠 Технологический стек

-   Framework: Angular 21 (Signals, standalone components).
-   Styling: [Tailwind CSS 4](https://tailwindcss.com/) --- использование последней версии с конфигурацией через CSS-переменные.
-   Icons: Lucide Angular.
-   Testing: [Vitest](https://vitest.dev/) + JSDOM --- быстрая альтернатива Karma/Jest.
-   Architecture: State Management через Facade Pattern.

🏗 Архитектура папок

Проект организован по принципам модульности:

-   `core/` --- синглтон-сервисы, модели данных и базовые слои (layout), доступные всему приложению.
-   `features/` --- функциональные блоки (бизнес-модули):
    -   `dashboard`: Аналитика и общая информация.
    -   `menu`: Управление ассортиментом пицц.
    -   `orders` & `add-order`: Работа с заказами.
-   `shared/ui-kit/` --- собственная библиотека UI-компонентов (Buttons, Inputs, Selects, Modals). Это позволяет сохранять единство дизайна и легко переиспользовать код.
-   `services/` --- разделение на:
    -   `*.api.ts`: Чистые HTTP-запросы к бэкенду.
    -   `*.facade.service.ts`: Слой абстракции, скрывающий сложность логики от компонентов.

💡 Особенности реализации

-   Custom UI Kit: Полностью кастомные компоненты форм (автокомплит, мультиселект, переключатели), стилизованные с помощью Tailwind 4.
-   Facade Pattern: Компоненты взаимодействуют только с фасадами, что упрощает их тестирование и делает код чище.
-   Modern Angular: Активное использование сигналов (Signals) для управления состоянием и асинхронности.
-   Dark/Light Mode: Поддержка тем оформления через `theme.service.ts`.

🚀 Запуск в разработке

Для локального запуска (требуется Node.js):

bash

```
npm install
npm start

```

Приложение будет доступно по адресу `http://localhost:4200`.
