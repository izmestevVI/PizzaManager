🧪 Pizza Manager Tests

Данный проект содержит набор автоматизированных тестов, обеспечивающих надежность бизнес-логики и корректность взаимодействия с базой данных.

🛠 Технологический стек

-   Test Framework: [xUnit](https://xunit.net/)
-   Infrastructure: [Testcontainers for .NET](https://dotnet.testcontainers.org/) --- запуск реального экземпляра PostgreSQL в Docker во время выполнения тестов.
-   Assertions: [FluentAssertions](https://fluentassertions.com/) --- для написания читаемых и выразительных проверок.
-   Mocking: [Moq](https://github.com/devlooped/moq) --- для изоляции сервисов от внешних зависимостей.
-   Code Coverage: Coverlet.

🏗 Ключевые концепции

🐳 Интеграционные тесты с Testcontainers

В отличие от классических тестов на In-Memory БД, здесь используется подход Infrastructure-as-Code.

-   При запуске тестов автоматически поднимается временный контейнер `postgres:18-alpine`.
-   Проект DbUp из основного решения накатывает миграции на этот контейнер.
-   Тесты выполняют реальные SQL-запросы через Dapper, проверяя фактическую совместимость кода с PostgreSQL.

🧪 Типы тестов в проекте

1.  Интеграционные тесты: Проверка репозиториев и цепочек «Сервис -> БД». Гарантируют, что сложные SQL-запросы и связи таблиц работают верно.
2.  Модульные (Unit) тесты: Проверка бизнес-логики сервисов с использованием `Moq` для подмены зависимостей.
3.  Тестирование API: Проверка корректности возвращаемых статус-кодов и структуры DTO.
